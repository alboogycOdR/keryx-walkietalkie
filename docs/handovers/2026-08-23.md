## Lessons for Flutter projects
Append to `C:\Users\Nuburo\Documents\BASILEIA\lekker swot\mobile\LESSONS.md`:
- **Permission plugin serialization (Android API 33+):** `permission_handler` on Android rejects concurrent `.request()` calls with `PlatformException` "request for permissions is already running." Sequential `await`s required; exception boundary (`try/catch` on `PlatformException`) must wrap all gate calls to degrade gracefully (show telltale on denial, don't crash). Non-blocking permissions (notifications, nearby-Wi-Fi) can chain sequentially without blocking app boot; blocking permissions (mic) should set a flag and display non-modal telltale on denial.
- **Mutation testing for regression tests:** Every new regression test must be reverted independently to confirm it fails without the fix. Tests that describe the intent rather than guard against regression slip through code review. Pattern: write test, fail it on clean build, apply fix, pass it, revert fix, confirm fail, restore fix, confirm pass. Do this before review submission.
